# AGENTS.md

## Project

Personal CSC173 deep-learning coursework repository using Python and TensorFlow/Keras.

- `lecture/`: lecture PDFs for reference.
- `activities/<number>/`: activity notebooks and accompanying notes.

## Working approach

- Complete requested work and explain the key reasoning in plain, technically correct language.
- Read the activity instructions and relevant lecture material before editing.
- Preserve instructor prompts, questions, and cell order. Edit solution code and answer cells as needed, following the notebook's existing style.
- Base observations and reported metrics on actual data and outputs. Keep required AI and outside-help disclosures accurate.

## Notebook workflow

- Support Google Colab and local VS Code/Jupyter equally. Follow each notebook's setup instructions.
- Keep paths and data loading compatible with both environments. Use the student's own photos and datasets where the assignment requires them.
- Preserve cell IDs, notebook metadata, and unrelated saved outputs. Retain outputs required for submission.

## Validation

- No repository-wide build or test suite is defined.
- After notebook edits, validate the notebook JSON and rerun affected cells with their dependencies when the runtime and data are available.
- Report what was actually checked and which cells or results could not be rechecked. Flag saved outputs that may be stale after code changes.
